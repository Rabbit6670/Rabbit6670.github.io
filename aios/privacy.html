Aipz1 개인정보처리방침

시행일: 2026-10-19

사용 대상

Aipz1은 개발자 본인 한 명만 쓰는 개인용 앱입니다. 다른 사람에게 제공하지 않습니다.

접근하는 정보

  • Gmail: 메일 목록과 내용 읽기, 라벨 붙이기, 답장 초안 만들기 (gmail.modify, gmail.compose)
  • Google 캘린더: 일정 읽기와 응답 (calendar.events)

사용 목적과 보관

가져온 정보는 본인의 할 일과 일정을 보여 주고 메일 정리를 돕는 데만 씁니다. 개발자 본인의 개인 서버에만 저장하며, 광고에 쓰거나 팔거나 다른 사람에게 넘기지 않습니다. 메일은 본인이 화면에서 직접 보내기를 눌렀을 때만 보내집니다.

Google 사용자 데이터

Aipz1's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

삭제

Google 계정의 서드파티 앱 접근 권한에서 언제든 Aipz1의 접근을 끊을 수 있습니다. 개인 서버에 저장된 정보는 개발자가 직접 지웁니다.
